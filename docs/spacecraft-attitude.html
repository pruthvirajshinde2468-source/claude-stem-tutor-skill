Spacecraft attitude — Euler angles, DCM and quaternions

Example output of the stem-tutor Claude skill, level normal. All text is written in ASD-STE100 Simplified Technical English. Values are example values for learning.

1. What it is

The attitude of a spacecraft is the direction in which it points. The attitude control system (ADCS) must know this direction to point the camera at the Earth, the solar panels at the Sun, and the antenna at the ground station.

There are three common ways to write one attitude as numbers:

  • Euler angles — three turns: yaw, pitch, roll. Easy for people to read.
  • DCM (direction cosine matrix) — a 3×3 table. It changes a vector from one frame to the other frame.
  • Quaternion — four numbers: one axis and one angle. Flight software uses this.
Everyday model for this topic: hold a phone in your hand. Turn it left (yaw), tip the top away from you (pitch), then tilt it to one side (roll). Now try one single turn about one tilted axis that gives the same end position. That single turn is the quaternion.

3. Equations

Direction cosine matrix from Euler angles (yaw-pitch-roll, 3-2-1):

$$R = R_z(\psi)\,R_y(\theta)\,R_x(\phi),\qquad R_z(\psi)=\begin{bmatrix}\cos\psi&-\sin\psi&0\\ \sin\psi&\cos\psi&0\\0&0&1\end{bmatrix}$$
SymbolPhysical object or motionPhysical / bookkeeping
$\psi,\theta,\phi$Yaw, pitch and roll angles: how far the body turns about each axis.Physical
$R$Each column is one body axis, written in the reference frame. Column 1 is where the nose (x axis) points.Physical
order $z\,y\,x$The sequence of the three turns.Bookkeeping — a different order gives a different attitude. Always write the order down.

Extremes: all angles 0 gives $R = I$: the body axes are on the reference axes. A matrix that is not orthonormal ($R^TR \ne I$) is not a rotation: the body is stretched, which is not possible for a solid spacecraft.

Back from the DCM to Euler angles:

$$\theta = -\arcsin R_{31},\qquad \phi = \operatorname{atan2}(R_{32},R_{33}),\qquad \psi = \operatorname{atan2}(R_{21},R_{11})$$

Hidden physics — gimbal lock: at $\theta = \pm 90°$, $R_{32}$, $R_{33}$, $R_{21}$ and $R_{11}$ all become 0. Then atan2 cannot find yaw and roll separately. The yaw axis and the roll axis are on the same line, and you lose one degree of freedom in the numbers. The spacecraft itself has no problem. Only the description fails.

Quaternion from one axis and one angle:

$$q = \begin{bmatrix} q_0 \\ \mathbf{q}_v\end{bmatrix} = \begin{bmatrix}\cos(\alpha/2)\\ \sin(\alpha/2)\,\hat{\mathbf{e}}\end{bmatrix},\qquad \lVert q\rVert = 1$$
SymbolPhysical object or motionPhysical / bookkeeping
$\hat{\mathbf{e}}$The single axis of the turn (a unit vector). Point your thumb along it: your fingers show the turn direction.Physical
$\alpha$The angle of the single turn.Physical
$\alpha/2$Half the angle.Bookkeeping — the half angle makes the algebra work when you multiply quaternions. Do not look for a "half turn" on the spacecraft.
$\lVert q\rVert = 1$Four numbers, but only three are free.Bookkeeping — normalize $q$ after each integration step.

Extremes: $\alpha = 0$ gives $q = [1,0,0,0]$: no turn. $\alpha = 360°$ gives $q = [-1,0,0,0]$: the same attitude. So $q$ and $-q$ are the same attitude. A quaternion has no gimbal lock at any angle.

Hand test: hold a book flat. Pitch it up 90° (nose up). Now "yaw" and "roll" turn the book about the same line. This is gimbal lock.

4. Procedure

  1. Write the three Euler angles and the turn order (here 3-2-1).
  2. Make $R = R_z R_y R_x$. Check that $R^TR = I$ and $\det R = +1$.
  3. To turn a vector from body frame to reference frame: $\mathbf{v}_{ref} = R\,\mathbf{v}_{body}$.
  4. For flight software, change to a quaternion. Normalize it.
  5. Change back to Euler angles only to show numbers to people. Check $\theta$ first: near ±90°, the yaw and roll values are not reliable.

5. Worked example

Data: the spacecraft turns 90° about the z axis. Where does the nose (body x axis) point?

  1. Quaternion: $\hat{\mathbf{e}} = [0,0,1]$, $\alpha = 90°$, so $q = [\cos 45°,\ 0,\ 0,\ \sin 45°] = [0.7071,\ 0,\ 0,\ 0.7071]$.
  2. Norm: $0.7071^2 + 0.7071^2 = 1.000$. Correct.
  3. Same turn as a DCM: $R = R_z(90°) = \begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix}$.
  4. Nose: $R\,[1,0,0]^T = [0,1,0]^T$.

Result: the nose now points along the reference y axis.

import numpy as np
def q_from_axis_angle(axis, angle_deg):
    axis = np.asarray(axis, float) / np.linalg.norm(axis)
    half = np.radians(angle_deg) / 2
    return np.concatenate(([np.cos(half)], np.sin(half) * axis))
print(q_from_axis_angle([0, 0, 1], 90))   # [0.7071 0. 0. 0.7071]

The spacecraft turns one full turn about one tilted axis (dashed line). The quaternion changes smoothly. Look at the Euler angles: they jump when pitch goes near ±90°.

7. Common errors

  • Do not mix turn orders. $R_zR_yR_x$ and $R_xR_yR_z$ give different attitudes.
  • Change degrees to radians before you use sin and cos.
  • Some libraries write the quaternion as $[q_1,q_2,q_3,q_0]$ (scalar last). Check the order before you use it.
  • Normalize the quaternion after each step. Small errors make $\lVert q\rVert \ne 1$, and then the attitude is wrong.
  • Do not trust yaw and roll when pitch is near ±90°.

8. Self-check

1. Write the quaternion for a 180° turn about the x axis. Which body axis keeps its direction?
2. Use the DCM from the worked example. Where does the body y axis point after the turn?
3. Make $R$ with $\theta = 90°$ and two different pairs of yaw and roll. Show that two pairs give the same $R$.
